# Knowledge Knight — starter website

A beginner-friendly, responsive educational website for Classes 5–8, built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout and responsive design
- `script.js` — class selector, notes, flashcards and quiz interactions

## Run it
1. Download and unzip the project.
2. Open the `knowledge-knight` folder.
3. Double-click `index.html` to open it in a browser.

No installation or paid service is required.

## Publish with GitHub Pages
1. Ask a parent/guardian to help create or use a GitHub account and review what will be public.
2. Create a new repository named `knowledge-knight`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's main branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Wait for GitHub Pages to publish the site. The Pages screen will show the website address.

## Important next steps
- The included notes, flashcards and quiz are sample content only.
- Before adding real school materials, check the correct syllabus and have a teacher or trusted adult review accuracy.
- Do not collect student names, email addresses, phone numbers, school names, locations or passwords.
- Do not add payments, ads, accounts or public leaderboards to this first version.
- Ask a parent/guardian to review the site before publishing it publicly.
