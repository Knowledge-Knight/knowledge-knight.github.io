# Knowledge Knight — Class 5 Starter

A responsive Class 5 learning portal using HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — white-and-blue design and responsive layout
- `script.js` — subject search, subject selection and resource selection

## Run it
Open `index.html` in a browser. No installation is required.
